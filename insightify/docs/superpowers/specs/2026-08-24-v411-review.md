### 4b. `code-parser.js` — Dead code reference

### 4d. `html-parser.js` — Removes `<header>` tag

### 4e. `build-html.mjs` — `inArray` variable declared but never read

## 8. 💡 Feature Opportunities

| Feature | Benefit |
|---------|---------|
| **Incremental re-run** | Only re-process changed sources (hash-based diffing in manifest) |
| **Search in HTML output** | Client-side text search (like Docusaurus) — enhances usability |
| **Export formats** | PDF export, Confluence/Notion markdown — broader adoption |
| **Config file schema** | `insightify.config.json` mentioned in orchestrator but no schema defined |
| **Non-React support** | Vue, Angular, Svelte, backend projects (Python/Go/Java) |
| **Syntax highlighting** | HTML output has `<code class="language-x">` but no Prism/Highlight.js — code blocks render plain |
| **Table of Contents per section** | Large sections hard to navigate without sub-ToC |
| **Progress persistence** | Write step completion to `.insightify/progress.json` for real `--resume` support |
